# 中学英単語

HTML / CSS / JavaScript だけで作った、スマートフォン対応の英単語学習サイトです。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。

## 機能

- **カードモード**：タップでカードをめくって答えを確認。左右スワイプ / 前へ・次へボタンで移動
- **英単語 ⇄ 翻訳 切替**：表に出すのを英語にするか日本語にするか切り替え
- **🔊 発音読み上げ**：ブラウザの Web Speech API で英単語を読み上げ
- **☑ 覚えたチェック**：覚えた単語に印を付け、進捗バーで確認。記録はブラウザに保存
- **一覧モード**：「英語のみ」「訳のみ」「両方」で表示。隠れた部分はタップで表示
- **絞り込み**：品詞別・未習得のみ・覚えたのみ
- **シャッフル**：出題順をランダムに
- ダークモード対応、PC ではキーボード操作も可能（← → で移動、Space でめくる、S で発音）

## 単語の追加

`js/words.js` の `WORDS` 配列に次の形式で追加してください。

```js
{ en: "apple", ja: "りんご", pos: "名詞", example: "I eat an apple.", exampleJa: "私はりんごを食べます。" },
```

## 公開（GitHub Pages）

リポジトリの Settings → Pages で公開するブランチを選ぶと、Web サイトとして公開できます。

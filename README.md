# 甲斐の英単語

HTML / CSS / JavaScript だけで作った、スマートフォン対応の英単語学習サイトです。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。

## 機能

- **シーン別**：中学生レベルの150語を「学校」「食べ物」「旅行・世界」など10のシーンに分類。シーンのボタンで絞り込み、シーンごとの進捗も表示。シーンの最後まで行くと次のシーンへ自動でつながり、最後のシーンの次は最初に戻る
- **カードモード**：タップでカードをめくって答えを確認。左右スワイプ / 前へ・次へボタンで、単語帳のページをめくるように次の単語へ
- **英単語 ⇄ 翻訳 切替**：表に出すのを英語にするか日本語にするか切り替え
- **🔊 音声読み上げ**：ブラウザの Web Speech API で英単語・例文を読み上げ
  - 自動読み上げ（カードを表示・めくったときに自動で発音）
  - 🐢 ゆっくり再生
  - 端末にある声から聞き取りやすい高品質な声を自動で選択（声の種類は自分でも選べます）
  - 読み上げ中はボタンが光る
- **☑ 覚えたチェック**：覚えた単語に印を付け、進捗バーで確認。記録はブラウザに保存
  - カードをダブルタップ：チェック切替（カードの上でも上下スワイプで画面はスクロールできます）
  - PC では ↑ キーで覚えた＆次へ、↓ キーでチェックを外す
- **一覧モード**：「英語のみ」「訳のみ」「両方」で表示。隠れた部分はタップで表示
- **絞り込み**：品詞別・未習得のみ・覚えたのみ
- **シャッフル**：出題順をランダムに
- ダークモード対応、PC ではキーボード操作も可能（← → で移動、Space でめくる、S で単語の発音、E で例文の発音）

## 単語の追加

`js/words.js` の `WORDS` 配列に次の形式で追加してください。`scene` は `SCENES` にある名前を使います（新しいシーンは `SCENES` に追加）。

```js
{ scene: "食べ物", en: "apple", ja: "りんご", pos: "名詞", example: "I eat an apple.", exampleJa: "私はりんごを食べます。" },
```

## 公開（GitHub Pages）

リポジトリの Settings → Pages で公開するブランチを選ぶと、Web サイトとして公開できます。
